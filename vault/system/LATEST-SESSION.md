# Checkpoint — rewrite me at the end of every session

The next session reads this file in full before touching anything else,
so write it for a reader with zero context. Replace the hints below with
real content each time; keep every section, even if a section's honest
content is "none".

## Objective

What the work is ultimately for, in one or two lines.

## State

Where things stand right now: what is done and verified, what is in
flight, what has not started. Name exact files and commands, not
paraphrases.

## Decisions

Every ruling made this session, each with its why. These are settled;
the next session does not reopen them.

## Open threads

What to do next, in priority order. Include anything blocked and what
it is blocked on.

## Gotchas

Dead ends already tried, traps discovered, things that look wrong but
are right. The expensive lessons this checkpoint exists to keep.
